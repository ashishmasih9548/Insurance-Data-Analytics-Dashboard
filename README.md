# Insurance-Data-Analytics-Dashboard using Power BI

## Project Overview
This project focuses on building an enterprise-grade interactive dashboard using Power BI to evaluate policyholder data, premium distribution, and claim analytics for the insurance sector.
Developed an interactive Power BI dashboard to analyze insurance data and visualize key business metrics for better decision making.
• Cleaned and transformed insurance data using Power Query.
• Built an interactive dashboard with KPIs, charts, and DAX measures.
• Analyzed claims, policy, and customer data to identify business trends.

**ETL & Data Cleaning:** Extracted raw operational datasets (~10,000+ records containing simulated real-world anomalies), transformed messy fields, and handled missing values using Power Query Editor.

**Calculated Metrics:** Applied advanced DAX formulas to create dynamic financial measures, loss ratios, policy conversion rates, and period-over-period KPIs.

**Business Insights:** Transformed raw transactional records into visual intelligence to aid decision-makers in risk management, customer segmentation, and revenue optimization.

## Features
**Large-Scale Data Ingestion:** Modeled 10,000+ relational records sourced via SQL Server enterprise pipelines.

**Custom KPI Tracking:** Real-time visibility into Total Premiums, Claim Ratios, Customer Retention Rates, and Average Claim Settlement Times.

**Advanced Data Cleaning:** Implemented robust M-code operations in Power Query to repair schema errors, standardized data types, and normalize demographic data.

**Role-Level Security (RLS):** Configured dynamic RLS roles to restrict data access based on user regions and departmental permissions.

**Cloud Publishing & Distribution:** Published live interactive reports to Power BI Service with scheduled data refresh and executive sharing capabilities.

## Technical Breakdown
📊 **Microsoft Power BI Desktop & Service:** Dynamic visual layouts, UI/UX optimization, conditional formatting, and cloud dashboard deployment.

🧹 **Power Query Editor:** Advanced Data Cleaning, ETL pipeline construction, anomaly remediation, and custom M-Scripting.

📐 **DAX (Data Analysis Expressions):** Complex calculated columns, measure tables, dynamic Time Intelligence (YTD/YoY), and KPI logic.

🔒 **Security & Administration:** Dynamic Role-Level Security (RLS) setup for regional data governance.

🗄️ **Data Architecture:** SQL Server Integration with dynamic Date Table mapping and Star-Schema modeling.
